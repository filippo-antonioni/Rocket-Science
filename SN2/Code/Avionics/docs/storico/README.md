# Documentazione storica

Questi documenti sono conservati integralmente per ricostruire lo sviluppo.
Per l'uso attuale partire da [README avionica](../../README.md) e
[USO.md](../USO.md).

Alcune istruzioni storiche fanno riferimento a cartelle `Avionics_v4` o
`ModalitaAvionics`, al GPIO18 del servo e ad ambienti PlatformIO non più
presenti. Non vanno applicate come procedure di installazione attuali.
