# Sketch originale del fairing

`Gestione_fairing.ino` è conservato senza modifiche come prova manuale del
servo. Lo sketch usa GPIO18, mentre il firmware attuale di banco usa GPIO17.
Non caricarlo aspettandosi i pin o i protocolli del progetto Avionics.

Per le prove attuali usare il [menu avionica](../Avionics/README.md).
